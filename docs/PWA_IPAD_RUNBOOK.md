# Final Call 第三關｜PWA 平板安裝與賽前檢查

適用設備：6 台 iPad 7（9.7 吋、橫向）。

本程式是離線優先的 PWA：**首次開啟與更新時需要網路**；完成快取驗證後，答題本身不需網路。

## 1. 發布前準備（開發／技術人員）

- [ ] 已通過 `corepack pnpm test`。
- [ ] 已執行 `corepack pnpm build`，確認 `dist` 已產生。
- [ ] 已將 `dist` 部署到固定的 HTTPS 網址。
- [ ] 使用一般瀏覽器開啟正式網址，確認首頁、倒數、答題、答錯重置、成功頁皆正常。
- [ ] 若本次有更新，確認 Service Worker 快取版本已提高；本專案目前由 `public/sw.js` 的 `CACHE_NAME` 控制。
- [ ] 將「正式網址」與本次 Git commit 紀錄在活動工作群組；不要讓工作人員從本機預覽網址或 IP 位址安裝。

> GitHub Pages 的網址可使用 `https://帳號.github.io/儲存庫名稱/`。首次安裝必須使用 HTTPS 正式網址。

## 2. 每台 iPad 安裝步驟

請依序在 6 台設備各做一次，並貼上設備編號貼紙：T1～T6。

1. 連上穩定 Wi-Fi，確認日期與時間正確，電量至少 80%。
2. 使用 **Safari** 開啟正式網址，等待首頁完全載入。
3. 點 Safari 的「分享」按鈕 →「加入主畫面」。
4. 若系統顯示「作為網頁 App 開啟」，保持開啟；確認名稱為 `Final Call 3` 後按「加入」。
5. 回到主畫面，從新建立的 Final Call 圖示開啟。
6. 確認開啟後沒有 Safari 的網址列、畫面為橫向，且能看見「開始入境挑戰」。
7. **保持連網至少 15 秒後關閉 App，再從主畫面重開一次。**這會讓 Service Worker 完成快取與接管。

Apple 的「加入主畫面」位置或文字會因 iPadOS 版本略異，但均從 Safari 的分享選單操作。

## 3. 離線驗證（每台必做）

1. 從主畫面關閉 Final Call App。
2. 關閉 Wi-Fi；若設備有行動網路，也關閉行動數據。
3. 從主畫面重新開啟 Final Call。
4. 點「開始入境挑戰」，等待倒數結束。
5. 任意作答一題，確認可顯示對錯與下一題／重新開始流程。

## 4. 活動前一日

- [ ] 6 台皆已通過離線驗證。
- [ ] 6 台均設為橫向使用，取消螢幕自動鎖定或將時間設為活動所需長度。
- [ ] 準備充電線與延長線；活動全程建議接電。
- [ ] 將 Final Call 圖示移至每台主畫面第一頁、明顯位置。
- [ ] 關閉不必要的通知、專注模式以外的干擾與 Safari 分頁。
- [ ] 指定一台 T1 作為「更新驗證機」，其他五台在確認無誤前不要更新。

### 建議：啟用引導使用模式

引導使用模式可暫時把 iPad 限制在單一 App，避免參賽者跳回主畫面或開啟其他內容。

1. 設定 → 輔助使用 → 引導使用模式 → 開啟，設定工作人員專用密碼。
2. 開啟 Final Call PWA 後，iPad 7 按三下 Home 鍵啟動。
3. 建議保留「觸控」開啟；關閉 Home 鍵／其他不必要硬體按鈕；不要設定時間限制。
4. 工作人員以三下 Home 鍵和密碼結束模式。

## 5. 活動當日開場前

- [ ] 每台接電、螢幕乾淨、音量依活動需求設定。
- [ ] 從主畫面開啟 Final Call，而非從 Safari 的舊分頁開啟。
- [ ] 確認皆停在「開始入境挑戰」首頁。
- [ ] 以 T1 再做一次完整流程：倒數 → 五題 → 成功 → 下一位參賽者。
- [ ] 若已完成離線驗證，可關閉 Wi-Fi，避免活動中網路跳出登入頁或干擾更新。
- [ ] 現場人員知道「結束本次挑戰」只供工作人員中止異常回合使用。

## 6. 更新版本時的固定流程

1. 技術人員部署新版本後，只先讓 T1 連網並從主畫面開啟 App。
2. 關閉 T1 App 後再開一次，完整驗證畫面與流程。
3. T1 確認後，再逐台讓 T2～T6 連網、關閉並重開 App。
4. 每台都完成一次離線驗證才算更新完成。

若畫面仍為舊版：確認正式網址是否正確、Wi-Fi 是否可用，關閉 App 後重開；最後手段才移除主畫面圖示並依第 2 節重新安裝。

## 7. 現場異常處理

| 情況 | 現場處理 |
|---|---|
| 點圖示後白畫面／無法開啟 | 先完全關閉 App 後重開；仍無效時開啟 Wi-Fi，以 Safari 開正式網址確認，再重新加入主畫面。 |
| 題目或流程卡住 | 工作人員以「結束本次挑戰」中止，回到待機頁後重新開始；必要時完全關閉 App 重開。 |
| 參賽者離開 App | 若已啟用引導使用模式，請工作人員確認模式是否仍在；未啟用則由主畫面重新開啟 Final Call。 |
| 裝置電量不足 | 立即接上備用充電線；不建議等電量過低才替換設備。 |
| 需要更換平板 | 新平板依第 2、3 節安裝並完成離線驗證後再上場。 |

## 8. 不要做的事

- 不要在活動進行中隨意清除 Safari／網站資料，這會移除離線快取。
- 不要只用 Safari 書籤取代「加入主畫面」；應從主畫面 Web App 圖示開啟。
- 不要在六台同時尚未驗證的狀態下直接更新版本。
- 不要依賴本機開發伺服器、`localhost` 或未加密 HTTP 網址作為活動正式版本。
